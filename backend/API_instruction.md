# Beauty Room API - Справочник для ИИ
## Обзор системы
Beauty Room - это система управления салоном красоты с полным REST API для работы с записями, клиентами, сотрудниками, услугами и аналитикой.

## Базовые CRUD операции

### Основные сущности
Все сущности поддерживают стандартные операции:
- **GET** `/api/{entity}` - получить список
- **GET** `/api/{entity}/{id}` - получить по ID
- **POST** `/api/{entity}` - создать новую
- **PUT** `/api/{entity}/{id}` - обновить
- **DELETE** `/api/{entity}/{id}` - удалить

### Список основных сущностей:

#### Управление персоналом
- **`/api/employees`** - сотрудники (с привязкой к специализации и квалификации)
- **`/api/specializations`** - специализации сотрудников
- **`/api/qualifications`** - уровни квалификации
- **`/api/schedules`** - расписание работы сотрудников
- **`/api/schedule_exceptions`** - исключения в расписании (перерывы, отпуска)

#### Управление клиентами
- **`/api/clients`** - клиенты
- **`/api/client_statuses`** - статусы клиентов
- **`/api/client_preferences`** - предпочтения клиентов

#### Услуги и комплексы
- **`/api/services`** - отдельные услуги
- **`/api/service_complexes`** - комплексы услуг
- **`/api/service_complex_pivot`** - связь услуг с комплексами

#### Записи и уведомления
- **`/api/appointments`** - записи на услуги (с расширенной логикой проверок)
- **`/api/notifications`** - уведомления клиентов

#### Аналитические данные
- **`/api/employee_workload`** - загруженность сотрудников
- **`/api/service_popularity`** - популярность услуг по месяцам

## Специальные возможности API записей

### Создание записи (`POST /api/appointments`)
**Поддерживает:**
- Запись на одну услугу (`service_id`) или комплекс (`complex_id`)
- Пользовательская продолжительность (`custom_duration`)
- Итоговая цена (`final_price`)

**Автоматические проверки:**
- Проверка рабочего времени сотрудника
- Проверка пересечений с другими записями
- Проверка исключений в расписании (перерывы)
- Валидация продолжительности процедур

### Обновление записи (`PUT /api/appointments/{id}`)
**Дополнительные поля:**
- `is_paid` - отметка об оплате
- `is_completed` - отметка о завершении
- `notes` - заметки к записи
- `status` - статус записи

## Аналитические эндпоинты

### Популярность услуг
- **`/api/analytics/service_popularity`** - анализ популярности услуг по периодам
- **`/api/analytics/service_popularity_comparison`** - сравнение популярности между периодами
- **`/api/analytics/service_seasonal`** - сезонный анализ услуг
- **`/api/analytics/service_correlation`** - корреляция между услугами

### Аналитика по сотрудникам
- **`/api/analytics/employee_workload`** - загруженность сотрудников
- **`/api/analytics/employee_workload_by_weekday`** - загруженность по дням недели
- **`/api/analytics/employee_efficiency`** - эффективность (выручка/час)
- **`/api/analytics/employee_specialization`** - специализация сотрудников

### Финансовая аналитика
- **`/api/analytics/financial`** - общая финансовая статистика
- **`/api/analytics/revenue_forecast`** - прогноз доходов

### Клиентская аналитика
- **`/api/analytics/clients`** - анализ клиентской базы
- **`/api/analytics/client_churn`** - анализ оттока клиентов

## Параметры запросов для аналитики

### Общие параметры
- **`start_date`**, **`end_date`** - период анализа (YYYY-MM-DD)
- **`group_by`** - группировка (day/week/month)
- **`limit`** - ограничение количества результатов

### Специальные параметры
- **`employee_id`** - фильтр по сотруднику
- **`service_id`** - фильтр по услуге
- **`inactive_days`** - дни неактивности для анализа оттока
- **`min_correlation`** - минимальная корреляция (0-100)

## Связующие таблицы (Many-to-Many)

- **`/api/appointment_service_pivot`** - связь записей с услугами
- **`/api/appointment_complex_pivot`** - связь записей с комплексами
- **`/api/specialization_qualifications`** - связь специализаций с квалификациями
- **`/api/service_qualifications`** - связь услуг с требуемой квалификацией

## Особенности работы с API

### Форматы данных
- **Даты:** ISO формат (YYYY-MM-DD)
- **Время:** ISO формат (HH:MM:SS)
- **Datetime:** ISO формат с timezone

### Обработка ошибок
- **400** - ошибка валидации данных
- **404** - сущность не найдена
- **409** - конфликт (например, занятое время)

### Специальные возможности
- Автоматическое создание БД при запуске
- CORS поддержка для фронтенда
- Подробное логирование операций
- Проверка целостности данных

## Примеры использования

### Создание записи
```json
POST /api/appointments
{
  "client_id": 1,
  "employee_id": 2,
  "service_id": 3,
  "datetime": "2024-05-25T14:00:00",
  "custom_duration": 90,
  "final_price": 1500.00
}
```

### Получение аналитики популярности
GET /api/analytics/service_popularity?start_date=2024-01-01&end_date=2024-12-31&limit=10


### Анализ загруженности сотрудников
GET /api/analytics/employee_workload?start_date=2024-05-01&end_date=2024-05-31&group_by=day
